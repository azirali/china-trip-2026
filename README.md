# Китай, поехали?

[Открыть сайт](https://azirali.github.io/china-trip-2026/)

Актуальная версия от **28 октября 2026**: поездка на скоростных поездах под купленные Астана ↔ Урумчи на **21 ноября — 1 декабря**. Прилёт 22 ноября 01:00; обратный вылет 1 декабря 02:00. Аэропорт вечером 30-го.

Три пары: Цзяюйгуань + Чжанъе, Урумчи + Турфан, Турфан + Чжанъе. Две основные туристические базы, Урумчи в дальних вариантах — транзит. Сравнение цены/времени, конкретные примеры поездов, календарь продаж, 11 дат, редактируемая смета, анимация, реальная карта и шуточный спутник.

[Актуальное руководство](rail-guide.md). [Предыдущая версия с внутренними перелётами](flight-options.html) сохранена для сравнения: её авиацены проверялись 10 октября и сейчас не обновлялись. Архивные документы и PDF в assets не являются текущим планом.

## Данные и ограничения

На 28 октября ноябрьские поезда ещё не продаются. Время/тарифы — осенние примеры Ctrip, часть страниц сентябрьская, часть октябрьская; наличие в ноябре не подтверждено. Пара Цзяюйгуань + Чжанъе: второй класс 336 + 65,5 + 401,5 = 803 CNY; дополнительные расходы с резервом 276 510 ₸. Урумчи + Турфан: 103 CNY, смета 210 010 ₸. Оба направления Турфана проверены по осенним спискам: по 51,5 CNY; ноябрьские даты ещё не продаются. Смета: 9 ночей, номер 160 CNY / двое, питание 80 CNY / день, курс 70 — допущение.

Купленные самолёты не входят в базовую сумму: поле ввода отдельно, пустое означает неизвестную полную цену. Paid airfare не сериализуется ни в URL, ни в localStorage. Сам PDF билета, паспортные данные и номера бронирований в репозиторий не добавляются. Комиссии посредников и окончательные цены сверять при покупке. Бани в выбранных городах не подтверждены; есть только необязательный бюджетный лимит. Гостиница автоматически не вычитается.

## Запуск и устройство

```sh
python3 -m http.server 4173
```

Статический HTML/CSS/ES modules без сборки и зависимостей. Основная версия: `index.html`, `rail-data.js`, `rail.js`, `rail.css`. Предыдущая: `flight-options.html`, `data.js`, `app.js`. Общие `styles.css`, `journey-animation.js`, `geo-map.js`.

GitHub Pages публикует корень `main`. Репозиторий не содержит собственных workflow: push вызывает штатную публикацию Pages. До push проверяются синтаксис, даты/смета и затронутые взаимодействия локально. Дополнительные workflow и повторные запуска CI не добавляются.

Карта Leaflet 1.9.4 и OpenStreetMap с атрибуцией; интернет нужен для тайлов, схема работает без них. Координаты городов географические, достопримечательностей ориентировочные. Линии показывают порядок, не точные трассы. Иллюстрации гор и крепости — код SVG, не фотографии. Внешний Google Fonts имеет системный fallback. Аналитики нет.

## Начальник экспедиции

По просьбе владельца добавлен шуточный спутник из предоставленного фото: `assets/friend-sticker.png`. Реплики меняются по маршруту и при превышении бюджета. Кнопка «Совет от бро» перебирает шутки. Это юмористический элемент, не реальные цитаты человека.

Фон удалён встроенным imagegen, без CLI. Промпт: background-extraction; вырезать только человека на прозрачный фон, сохранить лицо, выражение, волосы, одежду, руки, позу и перспективу; удалить окружение, близко кадрировать с небольшим прозрачным полем; без текста, новых объектов, обводки и тени. Обводка на сайте сделана CSS.
