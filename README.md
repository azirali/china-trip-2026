# Китай, поехали?

[Открыть сайт](https://azirali.github.io/china-trip-2026/)

Интерактивный план из Астаны на 25–26 ноября — 4 декабря 2026. Два друга, только две туристические базы, 9–10 дней, бюджет 500 000 ₸ каждому.

Три пары: Чэнду + Чунцин, Чунцин + Чжанцзяцзе, Сиань + Лоян. Шесть сочетаний с авиацией, календарь по дням, анимированные самолёты и поезда, географическая карта, настраиваемая полная смета и личный чек-лист. Ссылка сохраняет выбранный вариант; совместной базы данных нет.

[Текущее руководство](guide-25-november.md). PDF в assets и данные в archive относятся к прежним датам 11–20 ноября и не используются как актуальный план.

## Данные и ограничения

Проверка 7 октября 2026. Авиатарифы замечены в выдаче на двух взрослых, суммы на человека, окончательная оплата не проверена. Рекомендуемая связка Чэнду + Чунцин: все рейсы 200 115 ₸, смета с резервом 387 515 ₸. Жильё и расходы — плановые лимиты, ноябрьские поезда ещё не продаются. Курс сметы 70 ₸/CNY, официальный курс НБК на дату 67,66 ₸. Никаких бронирований сайт не делает. Все времена местные, Китай +3 часа к Астане.

## Запуск

Статический HTML/CSS/ES modules, без сборки и зависимостей:

```sh
python3 -m http.server 4173
```

Открыть http://localhost:4173. GitHub Pages публикует корень ветки `main`. Данные в `data.js`, анимация в `journey-animation.js`, географическая карта в `geo-map.js`, остальной интерфейс в `app.js`, стили в `styles.css`. Переключатель «Кино-схема / Точная карта» сохраняет текущий день и продолжает анимацию. Города нанесены по WGS84; линии между ними показывают последовательность поездки, а не точные трассы транспорта. Карта использует локальную копию Leaflet 1.9.4 (лицензия в `assets/vendor/leaflet.LICENSE`) и тайлы OpenStreetMap с видимой атрибуцией. Для геокарты нужен интернет; схема работает без тайлов. Внешний Google Fonts имеет системный fallback. Аналитика не подключена.

## Начальник экспедиции

По просьбе владельца добавлен шуточный спутник из предоставленного фото: `assets/friend-sticker.png`. Реплики меняются по маршруту и при превышении бюджета. Кнопка «Совет от бро» перебирает шутки. Это юмористический элемент, не реальные цитаты человека.

Фон удалён встроенным imagegen, без CLI. Промпт: background-extraction; вырезать только человека на прозрачный фон, сохранить лицо, выражение, волосы, одежду, руки, позу и перспективу; удалить окружение, близко кадрировать с небольшим прозрачным полем; без текста, новых объектов, обводки и тени. Обводка на сайте сделана CSS.
