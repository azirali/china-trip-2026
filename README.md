# Китай, поехали?

[Открыть сайт](https://shutovbro.github.io/china-trip-2026/)

Интерактивный план поездки из Астаны на 11–20 ноября 2026 года. Два друга, 10 дней, бюджет 500 000 тенге каждому.

Три маршрута по дням, шесть вариантов для сравнения, анимированная схема передвижений, настраиваемый бюджет, ссылки на найденные авиабилеты и поезда, локальный чек-лист и PDF на 16 страниц. Ссылка сохраняет выбор маршрута и настройки расчёта; совместной базы данных нет.

У схемы есть запуск, пауза, переход между днями и ползунок. Она показывает перелёты, поезда, экскурсии и возврат в Астану, а при смене маршрута перестраивается. Географическое расположение ориентировочное; длительность движения точки не обозначает реальное время в пути. При настройке уменьшенного движения автоматическое воспроизведение заменяется пошаговым просмотром.

## Данные и ограничения

Проверка 29 сентября 2026. Авиатарифы замечены в выдаче на двух взрослых; окончательная оплата и применимость специальных тарифов не проверены. Ноябрьские поезда ещё не в продаже, расписания ориентировочные. Отели и бытовые расходы — целевые бюджеты. Никаких бронирований сайт не делает. Все времена местные, Китай на 3 часа впереди Астаны.

## Запуск

Статический HTML/CSS/ES modules, без сборки и зависимостей:

```sh
python3 -m http.server 4173
```

Открыть http://localhost:4173. GitHub Pages публикует корень ветки `main`. Данные в `data.js`, схема в `journey-animation.js`, остальной интерфейс в `app.js`, стили в `styles.css`. Внешний Google Fonts имеет системный fallback. Аналитика не подключена.

## Начальник экспедиции

По просьбе владельца добавлен шуточный спутник из предоставленного фото: `assets/friend-sticker.png`. Реплики меняются по маршруту и при превышении бюджета. Кнопка «Совет от бро» перебирает шутки. Это юмористический элемент, не реальные цитаты человека.

Фон удалён встроенным imagegen, без CLI. Промпт: background-extraction; вырезать только человека на прозрачный фон, сохранить лицо, выражение, волосы, одежду, руки, позу и перспективу; удалить окружение, близко кадрировать с небольшим прозрачным полем; без текста, новых объектов, обводки и тени. Обводка на сайте сделана CSS.
