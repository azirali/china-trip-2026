# Китай, поехали?

[Открыть сайт](https://azirali.github.io/china-trip-2026/)

Интерактивный план под купленные **Астана ↔ Урумчи на 21 ноября — 1 декабря 2026**. Прилёт ночью 22-го, вылет домой 1 декабря 02:00: аэропорт вечером 30-го. Два друга и две туристические базы. Международные билеты уже куплены, их цена неизвестна.

Три пары: Чэнду + Чунцин, Чунцин + Чжанцзяцзе, Урумчи + Турфан. Календарь, самолёты/поезда в анимации, реальная карта, калькулятор с отдельными полями оплаченной и будущей авиации, две бани с ночным отдыхом и чек-лист. Ссылка сохраняет выбранный вариант и введённую цену билетов; совместной базы данных нет.

[Актуальное руководство](guide-21-november.md). Архивы и прежний PDF в assets относятся к старым датам и не являются текущим планом.

## Данные и ограничения

Проверка 10 октября 2026. Внутренние пары на двух взрослых, суммы на человека. Основной Чэнду: 129 262 ₸, смета дополнительных расходов с резервом 349 562 ₸. TFU-возврат 119 195 ₸ наблюдался в списке, финальные условия отдельно не подтверждены. Чунцин: 135 771 ₸, 5 кг ручная туда / 8 кг назад, 20 кг багажа. Ничего не бронируется.

Калькулятор не считает неизвестную цену международных билетов нулевой: до её ввода отображает дополнительные расходы и порог цены для полного лимита 500 000 ₸. Жильё и расходы — плановые лимиты, поезда на ноябрь ещё не продаются, курс 70 ₸/CNY — допущение. 9 гостиничных ночей включают 8 по маршруту и дополнительную короткую при раннем прилёте; поле ночей редактируемое. Бани добавляются как доплата, без автоматического вычитания жилья/еды. Баня Qianxi и ранний Улон исключают друг друга в основной паре.

Пакеты FUFU и Qianxi опубликованы продавцами, не подтверждены заведениями на выбранные даты. Казахстанский паспорт и регистрацию ночёвки уточнять до отмены отеля. Все часы официальные китайские UTC+8, на 3 часа впереди Астаны. В Синьцзяне в разговорах может встречаться UTC+6; поезда/авиация по UTC+8.

## Запуск

Статический HTML/CSS/ES modules, без сборки и зависимостей:

```sh
python3 -m http.server 4173
```

Открыть http://localhost:4173. GitHub Pages публикует корень ветки `main`. Данные в `data.js`, анимация в `journey-animation.js`, географическая карта в `geo-map.js`, остальной интерфейс в `app.js`, стили в `styles.css`. Переключатель «Кино-схема / Точная карта» сохраняет текущий день и продолжает анимацию. Города нанесены по WGS84; линии между ними показывают последовательность поездки, а не точные трассы транспорта. Карта использует локальную копию Leaflet 1.9.4 (лицензия в `assets/vendor/leaflet.LICENSE`) и тайлы OpenStreetMap с видимой атрибуцией. Для геокарты нужен интернет; схема работает без тайлов. Внешний Google Fonts имеет системный fallback. Аналитика не подключена.

## Начальник экспедиции

По просьбе владельца добавлен шуточный спутник из предоставленного фото: `assets/friend-sticker.png`. Реплики меняются по маршруту и при превышении бюджета. Кнопка «Совет от бро» перебирает шутки. Это юмористический элемент, не реальные цитаты человека.

Фон удалён встроенным imagegen, без CLI. Промпт: background-extraction; вырезать только человека на прозрачный фон, сохранить лицо, выражение, волосы, одежду, руки, позу и перспективу; удалить окружение, близко кадрировать с небольшим прозрачным полем; без текста, новых объектов, обводки и тени. Обводка на сайте сделана CSS.
