Возврат 29-го оставляет 33,5 или 38 часов до международного вылета. Возврат 30-го — 14 часов, отдельные билеты не дают защиты стыковки. Аэропорты CTU и TFU различаются. Для раннего TFU нужен подтверждённый ночной трансфер или отель у аэропорта.

Купленная международная авиация не входит в публичную смету. Пустое поле её цены означает неизвестную полную стоимость, а не ноль. Значение не сериализуется в URL и localStorage. PDF билета, паспортные данные и PNR не добавляются в репозиторий.

## Запуск и устройство

```sh
python3 -m http.server 4173
```

Статический HTML/CSS/ES modules без сборки. Текущая версия: `index.html`, `city-data.js`, `city.js`, `city.css`. Архив поездных вариантов: `nearby-rail-options.html`, `rail-data.js`, `rail.js`. Общие `styles.css`, `rail.css`, `journey-animation.js`, `geo-map.js`.

GitHub Pages публикует корень `main`. Собственных workflow нет: push вызывает штатную публикацию Pages. Перед одним итоговым push проверяются синтаксис, сметы, даты, переключение вариантов, карта и адаптивность. Лишние запуски CI не добавляются.

Leaflet 1.9.4 и OpenStreetMap с атрибуцией. Для тайлов нужен интернет, схема автономна. Координаты городов географические, прогулочных зон и достопримечательностей ориентировочные. Линии показывают порядок перемещений, не точные трассы. Аналитики нет.

## Начальник экспедиции

По просьбе владельца добавлен шуточный спутник из предоставленного фото: `assets/friend-sticker.png`. Реплики меняются по маршруту и при превышении бюджета. Кнопка «Совет от бро» перебирает шутки. Это юмористический элемент, не реальные цитаты человека.

Фон удалён встроенным imagegen, без CLI. Промпт: background-extraction; вырезать только человека на прозрачный фон, сохранить лицо, выражение, волосы, одежду, руки, позу и перспективу; удалить окружение, близко кадрировать с небольшим прозрачным полем; без текста, новых объектов, обводки и тени. Обводка на сайте сделана CSS.
